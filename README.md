# Online Banking System Using Python

## Project Description
This is a console-based Online Banking System developed
using Python and Object-Oriented Programming (OOP).

The application allows users to perform basic banking
operations with custom exception handling.

## Features
- Create a bank account
- Deposit money
- Withdraw money
- Check available balance
- View transaction history
- Validate transaction amounts
- Restrict withdrawals to ₹25,000 per transaction

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- Exception Handling
- Python Lists

## Custom Exceptions
1. InsufficientBalanceError
2. InvalidAmountError
3. DailyLimitExceededError

## How to Run

1. Install Python.
2. Download the project.
3. Open a terminal in the project folder.
4. Run:

```bash
python bank.py
```
